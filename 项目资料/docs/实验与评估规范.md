# 实验与评估规范（课题 C09）

> 负责人：C（A/B 按本册产出可评估的产物）。本文规定**指标口径、对照与消融设置、种子与统计检验、结果与图表格式、负结果纪律**。
> 结果文件字段见 [`接口契约.md`](接口契约.md) §2.4；字段定义只在那里写。

## 1. 任务形式化与指标口径

**任务**：对每条样本输出幻觉概率 $p \in [0,1]$，与标签 `is_hallucination` 比较，做二分类判别。**正类 = 幻觉（`is_hallucination = 1`）**。

| 指标 | 定义与实现注意 | 类型 |
|---|---|---|
| **AUC**（主指标） | `sklearn.metrics.roc_auc_score`；正类必须显式指定为 1，避免标签顺序导致数值反转 | 任务主指标 |
| **PR-AUC** | `average_precision_score`；类别不平衡时比 AUC 更能反映实际使用价值 | 任务主指标 |
| **查准 / 查全 / F1** | 在固定阈值下计算，同时报告默认阈值 0.5 与校准后的最优阈值（记录在 `threshold` 字段） | 任务主指标 |
| **宏/微 F1、混淆矩阵** | `f1_macro` / `f1_micro` + `{tp, fp, tn, fn}`（`要求.md` 2.3 条第 1 款对分类任务的要求） | 任务主指标 |
| **单样本延迟** | `latency_ms_mean`（含检索与特征提取），用于说明轻量化程度 | 效率指标 |
| **按类型分组指标** | 对 `challenge_type` 的每个取值分别计算查准/查全/AUC | 鲁棒性/分组分析 |

**报告口径**：所有指标一律报 **3 个种子的 mean ± std**，不得只报最好的种子。

## 2. 对照设置（必须齐备）

| 代号 | 对照 | 说明 |
|---|---|---|
| **B0 随机** | 均匀随机打分 | 下界参考（AUC ≈ 0.5），用于确认评估代码无误 |
| **B1 自评置信度**（主基线） | `1 − baseline_confidence` 作为幻觉分数 | 课题设定的比较对象；方法来源为模型自评/内部校准一类工作（见 [`../refs/文献综述.md`](../refs/文献综述.md) §5.1） |
| **B2 纯词面重叠** | 仅用 `overlap_f1` | 检验"语义一致性特征是否真的比浅层重叠更强" |
| **M 本方法** | 一致性特征组（蕴含 + 重叠 + 冲突）→ 判别器 | 主方法 |

**成功判据**：`AUC(M) − AUC(B1) ≥ 0.10`（课题书研究目标），以 3 种子均值比较，并给出配对检验 p 值。

**关于"复现公开基线"（`要求.md` 2.2 条第 3 款）**：本课题的公开基线即 **B1（自评置信度判别）**，其方法来源是已发表的自评/校准工作。需要如实说明：这些文献报告的是**校准误差与选择性预测**类指标，并未给出与本任务可比的 AUC；因此我们做到的"复现"是**方法复现**（按原方法实现自评置信度并作为判别分数），并以"随机基线 B0 的 AUC 应接近 0.5"作为评估代码正确性的自检，而**不是**声称复现了某个具体 AUC 数值。报告须明确写出这一边界，不得虚构原文指标。

## 3. 消融设计（≥3 组，`要求.md` 2.3 条第 3 款）

| 组 | 消融内容 | 负责人 | 预期观察 |
|---|---|---|---|
| Abl-1 | **构造算子消融**：三类挑战子集分别单独评估（等价于"去掉某一类退化"），并对比 normal 集 | A | 三类难度不等，定位难度来源 |
| Abl-2 | **特征组消融**：整组去掉（去 NLI 蕴含 / 去重叠特征 / 去冲突计数），逐组做 leave-one-group-out | B | 哪组特征贡献最大、对哪类幻觉最关键 |
| Abl-3 | **判别器替换**：LogReg ↔ GBDT ↔ 轻量 MLP；以及**概率校准**（Platt / 温度缩放）前后 | C | 性能是否对判别器选择敏感；校准对阈值指标的影响 |

每组消融必须有**独立结果目录与 exp_id**，并在报告中给出同名表格。

## 4. 种子与统计检验

| 项 | 约定 |
|---|---|
| 种子集合 | `[13, 42, 2024]`，统一入口 `src/common/seeding.py::set_seed` |
| 报告形式 | 每指标 `mean ± std`（3 个种子） |
| 显著性检验 | 对**同一批样本**上 M 与 B1 的逐样本分数差做 **配对 t 检验** 与 **Wilcoxon 符号秩检验**，显著性水平 α=0.05；两者都报（Wilcoxon 不假设正态） |
| 多重比较 | 分组评估（三类 × 多指标）会放大假阳性：报告时说明比较次数，必要时用 Holm 校正并在报告中标注 |
| 配对单位 | 以 `sample_id` 配对（同一样本上比较两个方法），不得跨样本配对 |
| 实现 | `scipy.stats.ttest_rel` / `wilcoxon`，汇总写入 `results/metrics/summary.csv`（见 [`接口契约.md`](接口契约.md) §2.4） |

## 6. 图表规范

- **全部自绘**：由 `results/metrics/` 的数据用 matplotlib 重新绘制，**禁止截图**他人论文图（`要求.md` 2.3 条第 6 款）；
- 绘图脚本化：`src/evaluation/plots.py`，给定 `exp_id` 可一键重绘，图与数据版本一致；
- 必备图清单：
  1. 按幻觉类型的 AUC/查准/查全分组柱状图；
  2. ROC 与 PR 曲线（M vs B1 vs B2 同图）；
  3. 混淆矩阵热图（最优阈值）；
  4. 特征分布对比（幻觉 vs 非幻觉，如蕴含概率箱线图）；
  5. 消融结果对比图；
  6. 校准曲线（可靠性图，判别器替换组）；
- 图中须标注样本量 n 与误差棒含义（std）；颜色与字体统一（`Noto Sans CJK` 已确认可用于中文出图）。

## 7. 失败分析与负结果纪律

- `要求.md` 1.5 条第 4 款：**负结果不扣分，隐瞒失败按学术不端处理**；
- 至少报告 1 组未达预期的实验，写法固定为三段：**现象**（指标数字）→ **原因假设**（可检验）→ **验证方式与结论**；
- 预设的负结果方向：**"答案过时"类样本的证据本身自洽**，纯一致性特征（答案↔证据蕴含）在原理上无法识别时序错误，预期该组 AUC 明显低于另两类。这组要主动跑、主动写，不作为"没做"处理；
- 任何被丢弃的实验（如崩溃、参数写错）也登记在 [`实验记录.md`](实验记录.md) 的失败登记表中，注明原因。

## 8. 人工抽检与一致性核验

1. 从 `dev-test` 随机抽 **100 例**（三类按比例），由**非 C 本人**（A 或 B）判定"该回答是否为幻觉"；
2. 与自动判别比较，报告**一致率**与 **Cohen's κ**（`sklearn.metrics.cohen_kappa_score`）；
3. κ < 0.6 时：先检查标签判定规则（回到 [`数据构造规范.md`](数据构造规范.md) §5），再检查特征-标签对齐，最后才讨论方法本身；
4. 抽检表存 `results/metrics/manual_audit.csv`，含 `sample_id`、自动标签、人工标签、分歧原因。
