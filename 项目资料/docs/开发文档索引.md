1. [`../README.md`](../README.md) → 建环境（三条命令）→ 跑 `python scripts/check_env.py` 确认退出码 0；
2. [`项目启动与实施指南.md`](项目启动与实施指南.md) §1（环境与依赖）→ §2（框架图，弄清自己在哪一层）→ §4（分工与 WBS，认领任务）；

## 4. 文档纪律

1. **文档与代码同批更新**：接口、参数、指标口径一旦变化，先改文档再改代码（或同一批），避免二者漂移；
2. **引用而非复制**：同一事实只在一份文档中定义，其他文档用链接引用（例如字段定义只在 `接口契约.md`，其他地方链接过去）；
3. **每份文档标注负责人**：见 §1 表格；负责人不写"其他人也能改"，但改动需在周会通报；
4. **不写未验证的数字**：文档中出现的指标、显存、耗时等数字必须来自真实运行记录（`results/metrics/`），并注明来源实验 ID。
